# Scientific workflow source snapshots

These files preserve the current numerical and inference tools in their original project-relative layouts. The [workflow map](../docs/workflows.md) follows the computation from input preparation through closure, experimental CFF replicas, GPD fitting, diagnostics, and forward-information comparisons. For runnable current analysis and all six manuscript plots, start with [analysis/](../analysis/README.md). Consult the [software guide](../docs/software.md#research-workflow-sources) for the role of each directory and required runtime artifacts.

This source snapshot includes historical development and diagnostics as well as accepted interfaces. Presence of a script does not certify its method or authorize rerunning a closed study. Original runtime guards remain in place. Gigabyte-scale operator caches and full optimization histories are not bundled; 54 compact model states are available in `../analysis/checkpoints/`, and the compact validated row bank used by the public interface is in `../data/experimental/banks`.

The installable, locally demonstrated APIs are in `../src`. Research scripts keep their original imports and may require the original runtime capsule, compiled libraries, configurations, manifests, and data. Source origins and hashes are in `../SOURCE_MANIFEST.json`. Tiktaalik-derived code retains its upstream license and notices.
